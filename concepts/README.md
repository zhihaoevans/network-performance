## 使用约定

- 文档类型：概念说明与资料整理，不代表本仓库已经实测。
- 初次整理日期：2026-11-01。
- 具体行为需结合内核、驱动、网卡和 DPDK 版本确认。
- 上游网页可能随版本更新；实验报告应记录实际使用版本。
- 新增术语时写清：中文、英文/缩写、定义、性能意义和常见误区。
- 后续实验使用[实验报告模板](../templates/experiment.md)，知识深化使用[笔记模板](../templates/note.md)。

# LAB-005：DPDK 转发性能矩阵

状态：待执行，需要真实实验端口与独立发包/接收能力。

## 环境与基线

按 [testpmd 指南](../dpdk/baseline-and-testpmd.md)准备。记录 DPDK commit/release、编译模式、PMD、NIC/固件、IOMMU、内存页和 CPU/NUMA。保存设备绑定恢复信息。

## 实验矩阵

| 维度 | 建议试验点 | 说明 |
| --- | --- | --- |
| 帧长 | 64、128、512、1518 byte | 明确含不含 FCS，确认工具口径 |
| 流数 | 1、多个均匀流、重流偏斜 | 核对 RSS 字段 |
| 转发核数 | 1、2、4（可用范围内） | 单独保留主线程资源 |
| 队列数 | 与工作映射匹配的多组 | 不默认队列越多越好 |
| burst 上限 | 8、16、32、64 | 比较吞吐与延迟 |

先固定一组基础配置扫帧长，再逐项变化其他维度，不必穷举所有组合。

## 每次运行

启动并核对端口映射 → 预热 → 记录起始计数 → 固定窗口发流 → 停止发流 → 排空 → 记录计数。发送和接收双方都校验实际流量与帧内容，避免把黑洞当成高性能转发。

## 验收

记录每个负载点的接收 PPS、丢失比例、输入流量、CPU、延迟和异常计数。按事先定义的丢包阈值估计可持续速率，不把峰值称为“无损线速”。

结束按设备实际绑定模型恢复；完整步骤见 testpmd 指南。

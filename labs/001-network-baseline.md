# LAB-001：建立网络性能基线

状态：实验设计，尚未执行；本页没有实测结果。

## 目标

建立后续调优的参照，确认环境、负载定义和重复测量方法。

## 环境选择

- 优先使用两台可控制的 Linux 主机，明确中间链路和设备。
- 可从虚拟机或 network namespace 开始，但必须标记环境，结论不能直接外推到物理网卡性能。
- 发送端和接收端都要记录资源占用。

## 执行清单

1. 复制[实验模板](../templates/experiment.md)，保存为本目录下的基线报告。
2. 记录硬件、系统、工具版本、链路、MTU、队列、CPU/NUMA 与拓扑。
3. 定义固定负载，先测 TCP 单连接吞吐量，明确测量层次和统计口径。
4. 设定预热和稳定测量窗口，重复至少 3 次，保留每次原始结果。
5. 同步记录 CPU、丢包与重传；没有延迟测量时写 N/A，不由吞吐量推断 P99。
6. 对换方向复测，记录差异；多连接测量作为独立条件。
7. 分析波动和疑似瓶颈，选出下一项单变量实验。

## 验收标准

- [ ] 完整环境表与拓扑。
- [ ] 明确命令、运行位置、负载和指标口径。
- [ ] 至少 3 次同条件结果，解释明显波动。
- [ ] 原始记录完成脱敏。
- [ ] 一个有证据支持的观察和一个待验证假设。
- [ ] 不把设计、估算或单次峰值写成已验证结论。

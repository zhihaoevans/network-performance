# LAB-007：转发与异步检测闭环

状态：工程实验设计，尚未实现完整示例程序。

## 目标

比较基础转发、特征提取、异步上报、完整检测四种配置，量化新增功能成本。适用于协议识别、防火墙检测或设备侧推理项目。

## 控制变量

固定包长、流数、规则/模型版本、线程、NUMA 与输入流量。模型推理可以先用可控耗时模拟，但必须标为模拟，不能报告为真实模型性能。

## 注入场景

| 场景 | 验证点 |
| --- | --- |
| 检测正常 | 策略正确应用与端到端生效时间 |
| 检测变慢 | 队列有界、背压/降级行为符合设计 |
| 队列满 | 特征丢弃与转发是否按约定处理 |
| 流结束后结果返回 | 旧结果不能作用于新流 |
| 更新模型/规则 | 版本一致性与资源回收 |
| 检测线程退出 | 故障恢复与可观测状态 |

## 报告

输入/输出 PPS、转发丢包、特征上报率、检测队列深度、结果耗时分位数、过期结果数、降级次数、CPU 与内存。将策略准确性和性能分别统计。

## 验收

压力下队列与内存有界，流标识/版本处理正确，停止与恢复步骤完整。设计见[多核与检测](../dpdk/multicore-and-detection.md)。
